**Keep your development stack tidy.**

Terminalis is a focused macOS terminal workspace for organizing projects, services, saved commands,
and local development stacks. Give every job its own terminal, working directory, environment, and
commands—then group related terminals and control the whole stack together.

This repository is the public home for Terminalis releases and community feedback.

## What Terminalis does

- **One terminal per job.** Keep each project or service in a focused, real interactive terminal.
- **Remember the context.** Save working directories, environment variables, and frequently used
  commands.
- **Control stacks by tag.** Group related services and start or stop them together.
- **Show status at a glance.** See which commands are running, stopped, or need attention.
- **Notify you when work finishes.** Jump from a completion or failure notification to the terminal
  that sent it.
- **Keep your workspace local.** Terminalis requires no account and includes no advertising,
  telemetry, or Terminalis-operated cloud storage.

## Download Terminalis

Current releases support Macs with Apple silicon.

1. Open the [latest release](https://github.com/achekulaev/terminalis.app/releases/latest).
2. Download the macOS `.dmg` from the release assets.
3. Open the disk image and drag Terminalis into your Applications folder.

Official release DMGs are signed with Developer ID and notarized by Apple. Each release also
includes a SHA-256 checksum file so you can verify the download before installing it.

## Report a bug

Before opening a report, please [search the existing
issues](https://github.com/achekulaev/terminalis.app/issues) to see whether it is already known. If
not, [open a bug report](https://github.com/achekulaev/terminalis.app/issues/new?title=%5BBug%5D%20)
and include:

- your Terminalis version, macOS version, and Mac model or chip;
- the steps that reproduce the problem;
- what you expected and what happened instead; and
- screenshots or relevant logs, when they help explain the issue.

Terminal output and configuration can contain private paths, commands, environment values, tokens,
and other secrets. Remove sensitive information before posting anything publicly.

## Request a feature

[Open a feature request](https://github.com/achekulaev/terminalis.app/issues/new?title=%5BFeature%20request%5D%20)
and describe the workflow or problem you want to improve, who it affects, and what a useful outcome
